# The Classic Biryani — Pune

Premium responsive restaurant website for **The Classic Biryani, Wadarvadi, Pune**.

## Highlights
- Premium restaurant landing experience
- Real menu sections and pricing snapshot
- WhatsApp ordering and enquiries
- Table, family, group and party booking request flow
- Google Maps location and directions
- Customer review highlights
- Responsive mobile and desktop layout
- Food gallery, animations and modern UI

## Live Website
GitHub Pages: https://satitech-admin.github.io/classic-biryani-/

## Tech
HTML5, CSS3, JavaScript, Font Awesome and Google Fonts.
